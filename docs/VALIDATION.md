## Current release: v0.6.2 — November 19

See [distribution instructions](DISTRIBUTION.md).

The combined Setup EXE was built successfully (219,913,146 bytes). TypeScript, formatting, all 68 unit tests and both desktop workflows against `distribution/win-unpacked/ENS Wind Tunnel.exe` passed. Static checks confirmed `asInvoker` manifests for setup and both app architectures, correct x64/ARM64 PE machine types, no elevate helper, matching bundled application version/source output, and serial modules importing only Windows system DLLs. Both embedded 7z payloads were independently decompressed to hash streams; their actual executables and app.asar resources match the verified unpacked builds. `distribution/verification.json`, `release-manifest.json` and `SHA256SUMS.txt` record the results. No installer or extracted payload was executed during archive verification. Native ARM64 runtime execution, Windows 10 and fresh-account install/upgrade/uninstall remain untested.
